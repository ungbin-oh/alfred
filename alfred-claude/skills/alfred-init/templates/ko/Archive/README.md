# Archive — 보관 공간

지금은 쓰지 않지만 버리지 않는 것을 둔다. 부팅 브리핑과 프로젝트 찾기는 여기를 보지 않는다 —
꺼내 쓰려면 "archive 에 있는 X 이어서" 라고 짚는다.

- `workspace-archive/` — 산출물. project-workspace 와 같은 모양 (경로가 출처). git 에 올리지 않는다 (용량)
- `log-archive/` — 기록(log · open · trace). project-logs 와 같은 모양. git 으로 추적
- 넣거나 꺼낼 때 아래 표를 고친다. 꺼낸 것은 행을 지우지 말고 `꺼냄` 에 날짜를 적는다

## 보관 중
