# Timeline 예시

daily 의 `## Timeline` 절이 어떤 모양이어야 하는지 보여 주는 참조 파일이다.
아래 하루는 지어낸 예시다 — 논문 실험 프로젝트 하나를 만진 날.

**베낄 것은 겉모양이 아니라 아래 여섯 가지다.**

1. **출처가 trace 헤더다.** 기억으로 쓰지 않는다. 시각도 수치도 trace 에 적힌 그대로
2. 덩어리를 시계가 아니라 **국면이 바뀐 지점**에서 끊는다. 하루가 두 덩어리면 두 개로 쓴다
3. 한 줄에 **사건 하나**. 서술하지 않는다
4. **하루의 방향을 바꾼 결과만** 굵게. 전부 굵으면 아무것도 안 굵은 것과 같다
5. **막다른 길과 오진을 남긴다.** 지우면 하루가 매끄러워 보이고 나중에 왜 그 길로 갔는지가 사라진다
6. **맨 위에 요약 표, 그 아래 덩어리별 상세.** 표 한 행 = 덩어리 하나, 번호를 상세 제목과 맞춘다.
   하루를 한눈에 보고 필요한 덩어리만 내려 읽는다

여러 프로젝트를 만진 날은 시각순으로 섞되, **프로젝트가 바뀌는 덩어리 제목에 이름을 붙인다**
(`③ 14:00–16:30 · [Survey-Paper] 표 재작성`). 하루가 한 프로젝트면 맨 위에 한 번만 적는다.

**① 09:40–11:50 · 기준선 재현**
- 논문 저자 코드로 기준선 재현 시작
- 정확도 71.2 — 논문 수치 74.0 과 2.8 차이
- 난수 시드 탓으로 보고 시드 5개 반복 → 편차 0.3, 시드 문제 아님
- 전처리 단계에서 이미지 크기가 논문과 다름을 발견
- **크기를 맞추자 73.8 → 기준선으로 확정**

**② 13:10–15:30 · 실험 조건 정리**
- 조건 후보 6개 나열
- 팀 미팅 전 셋으로 줄이기로 함 (시간 예산)
- 학습률 스윕 3점 → 가장 큰 값에서 발산
- **발산을 모델 문제로 봤으나 warmup 누락이 원인** → warmup 추가 후 수렴

**③ 16:00–18:20 · 첫 본실험**
- 조건 A 학습 시작, 중간 체크포인트 저장 경로 오류로 1회 재시작
- 조건 A 74.9, 기준선 대비 +1.1
- 조건 B 는 메모리 초과 → 배치 절반으로 재시도, 결과는 내일
- **다음 날 첫 작업: 조건 B 결과 확인** ← 이어받을 지점
