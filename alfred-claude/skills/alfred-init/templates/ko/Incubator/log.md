# Incubator — 질문과 덜 익은 생각이 내려앉는 곳

## 목표

지금 어느 프로젝트에도 속하지 않는 것을 둔다: 궁금해서 물은 것, 공부한 것, 연구 잡생각,
다른 일을 하다 그 범위를 벗어나는 의문. 출처는 가리지 않는다.

## 전제

- Incubator 는 그 자체로 프로젝트(code INC)이면서, 아직 다른 곳으로 띄우지 않은 하위 프로젝트의 자리다 (공통 규약 2절)
- 하위 프로젝트는 내가 말할 때만 띄운다: `Incubator/<하위>/` 에 자기 code · log · trace, status 는 incubating.
  workspace 는 `project-workspace/Incubator/<하위>/` 에 두고 git 을 따로 둔다
- 하위 프로젝트가 자라면 진행할 카테고리로 폴더째 옮긴다 (log 쪽 · workspace 쪽 둘 다). 그만두면 Archive 로
- 여기에는 decision.md 를 두지 않는다 — 목적이 한 갈래가 아니다. 하위 프로젝트의 "왜" 는 띄우기 전까지 open 항목에 둔다 (공통 규약 14절)
