# Archive

What isn't in use now but is kept. The boot briefing and project search don't look here —
to bring something back, say "continue X in the archive".

- `workspace-archive/` — outputs, same shape as project-workspace (the path says where it came from). Not in git (size)
- `log-archive/` — records (log · open · trace), same shape as project-logs. Tracked in git
- Update the table below whenever something goes in or comes out. Things taken out keep their row, with the date under "Taken out"
