# alfred-init — Codex 판에서 다른 점

written by Ungbin_Oh · created 2026-10-05 · updated 2026-10-06

> **한국어 번역본이다.** 정본은 `alfred-codex/skills/alfred-init/SKILL.md` (영어) 이고 Codex 는 이 파일을 읽지 않는다.
> 대부분은 Claude 판([alfred-init.md](alfred-init.md))과 같다. 여기에는 다른 점만 적는다.

- **설정 파일은 `AGENTS.md`** — `templates/<lang>/AGENTS.md` 로 만든다. 이미 있으면 덮어쓰지 않고, 끝에 Alfred 설정 절을 덧붙일지 / 멈출지 채팅 관문으로 묻는다
- **규약을 워크스페이스에 복사하지 않는다** — `.alfred/rules.md` 도, `@.alfred/rules.md` 줄도 없다. 세션 시작 훅이 규약을 세션마다 넣는다
- **질문 창** — `request_user_input` 이 켜져 있으면 그것으로. 켜는 것은 셋업 때 한 번 치는 `codex features enable default_mode_request_user_input` (`~/.codex/config.toml` 에 남아 계속 켜져 있다). 꺼져 있으면 그 명령을 치고 Codex 를 다시 열라고 한 번 알리고, 그동안은 채팅으로 한 번에 하나씩, 선택지를 적어서 묻는다
- **질문 창 규칙 하나** — 질문 창으로 묻는 단계에서는 `request_user_input` 호출이 바로 다음 행동이다. 그 전에 채팅에 아무것도 쓰지 않는다
  (요약 · 선택지 · "창에서 답해 주세요" 모두). 사이에 다른 도구도 돌리지 않고, 질문 뒤의 말은 답을 받은 뒤에 쓴다.
- **채팅 관문 — Codex 가 창으로 묻지 않는 질문** — Codex 자체 지시가 허락을 구하는 질문과 진행 전에 꼭 받아야 하는 답에는
  `request_user_input` 을 쓰지 말고 채팅으로 물으라고 한다. 그래서 세 단계는 창이 아니라 채팅으로 묻는다: 기존 `AGENTS.md`(1단계),
  생성 확인(3단계), git(5단계). 관문마다:
  - 질문 한 줄을 **굵게**, 그다음 무엇을 입력할지 한 줄을 **굵게** 쓴다. 창이 없으니 "선택" 이 아니라 "입력" 이다.
    예: **"아래 입력창에 `생성` · `설정 다시 하기` · `중단` 중 하나를 입력해 주세요."**
  - 그 두 줄로 턴을 끝낸다
  - 다음 메시지가 답이 아니면(또는 "응" 같은 분명한 같은 뜻이 아니면) 그 말에 답하지도 실행하지도 않는다. **셋업이 아직 안 끝났다**는 것과
    무엇이 남았는지(3단계: 아직 아무것도 안 만들었다 / 5단계: git 을 아직 안 정했다)를 굵게 알리고, 그 질문은 셋업 뒤에 다시 해 달라고 한 뒤
    굵은 "입력해 주세요" 줄을 다시 쓴다. 답이 올 때까지 매번
  - "중단" · "취소" 는 언제든 그 자리에서 셋업을 끝낸다
- **생성 확인** — 설정과 만들 것의 짧은 요약(파일 수 · 맨 위 항목 두세 줄) 뒤에 관문 두 줄. 전체 목록은 달라고 할 때만
- **git 질문** — 만들었다는 한 줄 뒤에 관문 두 줄 (`git 사용` · `지금은 안 함`). `git 사용` 일 때만 `git init`. 마무리 안내는 답을 받은 뒤 한 번에
- **창 하나에 질문 셋까지** — 그래서 2번 창은 사용자 이름 · 호칭 · 비서 이름, 3번 창은 카테고리 · 저작 헤더
- **상태줄 배지 절이 없다** — Codex 는 사용자 상태줄을 지원하지 않는다. 그래서 "마무리 안내" 가 5절이 된다
- **마무리 안내** — 같은 폴더에서 Codex 를 다시 열어야 한다 (그냥 `codex`). 처음 열 때 Codex 가 플러그인 훅을 검토 · 신뢰하라고 묻고, 신뢰 전에는 규약이 들어가지 않는다
- **Incubator 뼈대** — Claude 판과 같다 (`project-logs/Incubator/` 의 log.md · open.md · trace/, `project-workspace/Incubator/`). 예시 파일 수는 19개
- **가이드 모드 안내** — Codex 호출 이름으로: `$guide-mode on` · `$guide-mode off`, "다시 연 뒤" 라고. 마무리 안내의 맨 끝은 굵은 "지금 이 폴더에서 Codex 다시 열기" (훅 신뢰 안내 포함)
- 마커 `.alfred/workspace` 의 version 은 0.4.1
